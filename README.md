# Greenthumb Abbey — Mods & Fun Projects

**Creator Attribution:** His Grace The Duke of Errol, The Dude of Greenthumb Abbey

Static HTML/CSS/JS showcase website for `greenthumbabbey.com` featuring mods and fun projects from Burnt Thumb Works' modding workshop (`C:\Boneworks\`). Zero dependencies, no build step, deployable directly on Porkbun Static Hosting or GitHub Pages.

## Pages
- `index.html` — Landing page, featured mods filterable by game, and supported game lanes
- `mods.html` — Detailed breakdown of controls, features, compatibility, and Steam Workshop links
- `about.html` — Workshop ethos and link to `burntthumbworks.com`
- `404.html` — Custom not-found page

## Local Preview
```powershell
python -m http.server 8090
```
Open `http://127.0.0.1:8090/`.
